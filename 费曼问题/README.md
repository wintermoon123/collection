# 费曼问题 · 资料夹说明

这个文件夹是「费曼 10 问」时间轴的唯一数据源。网站的时间轴模块直接读取 `timeline.js`，因此**更新网站不需要改 `index.html`**，只要维护这里的文件。

## 文件清单

| 文件 | 作用 | 谁来改 |
| --- | --- | --- |
| `timeline.js` | 时间轴数据源，网站实时读取 | 每次有新思考/资料就改这一个文件 |
| `费曼10问.md` | 10 个问题的原始笔记（母题 + 真正在问 + 往里攒） | 问题本身有调整时改 |
| `README.md` | 本说明 | 基本不用改 |

## 怎么更新网站上的时间轴

1. 打开 `timeline.js`，在数组 `window.FEYNMAN_TIMELINE = [ ... ]` 的**最前面**加一条记录：

```js
{
  date: "2026-11-25",          // 日期，YYYY-MM-DD
  title: "读到这里想到的事",    // 标题
  type: "思考",                 // 思考 / 资料 / 里程碑 三选一
  text: "正文写在这里。",       // 正文
  q: [1, 5],                   // 选填，关联的问题编号
  source: {                    // 选填，参考资料链接
    label: "资料名称",
    url: "https://..."
  }
},
```

2. 如果有新的原始资料（文章、笔记、截图），也放进这个文件夹，并在 `source.url` 里指向它。
3. 提交到 GitHub，网站会在几十秒后自动更新。

## 注意事项

- `date`、`title`、`type`、`text` 四个字段必填；`type` 只能是 `思考`、`资料`、`里程碑`。
- 新记录放最前面，时间轴会按数组顺序显示（最新的在上）。
- 记得在对象末尾加英文逗号 `,`，否则脚本会报错、时间轴不显示。
- 数组最后一条**不要**加逗号，兼容性最好。
